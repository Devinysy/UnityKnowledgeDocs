## 收录检查项

新增仓库前，至少检查：

- 是否为原始仓库，而不是不明镜像
- 最近更新时间和 Issue 状态
- 是否已经归档
- License 是否允许目标用途
- 与当前 Unity 或 Package 版本是否对应
- 推荐查看的具体目录或示例
